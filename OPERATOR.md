## 1. Rule that outranks the tools

| Mode | Agent may | Agent must not |
|------|-----------|----------------|
| **Read** | Repos, docs, logs, Drive (read), n8n status, screenshots | — |
| **Propose** | PRs, copy, schemas, workflow diffs, grades | Silent merge |
| **Write / effect** | Only after explicit approve | Deploy, billing, Drive mutate, n8n activate, secrets |

Same law as Meta Supreme workflows: **reads flow · writes wait.**
