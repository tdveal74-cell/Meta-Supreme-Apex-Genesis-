# Meta Supreme Apex Genesis — Web

Next.js frontend for the Intelligence Operating System.

## Design System

- Primary: Deep Navy `#0A1628`
- Accent: Amber Gold `#D4A017`
- Surface: Warm Off-White

## Run locally

```bash
pnpm install
pnpm dev
```

Open http://localhost:3000

## Structure

- `app/` — App Router pages
- `components/` — UI and layout components
- `lib/` — utilities
