Operations

The one job that is yours

Everything runs on its own except the decisions. The operating burden is not uptime or tuning — it is answering gates. The daily loop takes minutes; skipping it stops the system.

  1. Answer your gates

    Read the rendered payload — the actual text that would be written. Approve, edit first, or reject. A rejection halts the run and keeps its reason; nothing is lost by refusing.

  2. Check what the Council recalled

    If memory use is climbing while answers get worse, you have accumulated a bad memory. Correct or pause it — bad memory compounds into every future answer.

  3. Watch simulated mode

    If the provider is mock, every response is labeled simulated. Deterministic, offline, useful for testing flows — useless for actual judgment.

  4. Weekly: ten minutes

    Gates older than a few days, token spend by workflow, memory hygiene, halted-run patterns, and schedule health. A pattern of rejections means the workflow's prompt is wrong — edit the step.

What drives the bill

Three settings, in order of how much they hurt.

full_council: true×3 Nine seats instead of 3–4 — roughly triples a run.
deliberate: true×2 A second round where every agent re-reads the others.
trigger: hourly×24 Hourly is 24× daily. This is the one that actually hurts.
All three together ≈ 50× a single-agent daily run. There is no budget cap — watch the per-run token records yourself.
Doctrine

Non-negotiables

The rules the whole product rests on. They hold in every mode, on every plan, in every environment.

  1. 01Not a chatbot — Council and synthesis only
  2. 02Humans decide; agents recommend
  3. 03Automation never commits effects unattended
  4. 04Memory is transparent, editable, deletable
  5. 05Simulated output is always labeled simulated

Never

  • Never set WORKFLOW_APPROVAL_REQUIRED=false — it silently removes the guarantee everything rests on, and no incident is fixed by it.
  • Never edit the frozen baseline schema — changes ship as migrations.
  • Never resolve someone else's gate — approvals are recorded under your user id, and a shared account makes the audit trail a fiction.
  • Never downgrade past the migration that holds workflow_runs — that is where every approval record lives.

What it will not do — and says so

  • Send anything outbound. Exports render into the run record for you to read and copy.
  • Bill anyone, or share permissions across a team.
  • Enforce a spend limit for you.
  • Decide anything. It recommends; you record the call.
