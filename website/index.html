The eight filing laws

        
Every law is here because something broke without it,
           and each carries the failure it prevents.

        
01

          
Root holds the vault and nothing else

          
Never write a new file to root. Never leave a file at root "for now."

          prevented: 160 items accumulating at root, including a plaintext private key
        

        
02

          
Read the newest sibling before writing a new version

          
List the folder, sort by date, read the newest in full. It may already be the merge.

          prevented: the naming convention forking twice, sixty seconds apart
        

        
03

          
A success response is a claim. A validated read-back is a receipt.

          
Every move, rename, create or delete is confirmed by reading state back.

          prevented: a guard firing correctly for the wrong reason
        

        
04

          
Exact duplicates die on sight. Distinct versions are the owner's ruling.

          
Identical title, identical byte size, older timestamp: trash it. Anything else is a distinct version. A model does not decide which draft survives.

          prevented: keep-latest deleting an addendum holding four rulings that existed nowhere else
        

        
05

          
Filenames that carry warnings are canon

          
Titles carrying instructions outrank any general heuristic. Read every filename before acting on any file.

          prevented: a literal keep-latest pass deleting the only copy of four rulings
        

        
06

          
Retire by moving and renaming, not by deleting

          
Superseded material moves to the archive with its status in the filename. Deletion is final.

          prevented: a trashed file the connector could never restore
        

        
07

          
Sweep to a dated holding folder. Never route in bulk blind.

          
A pile that is not understood moves whole into a dated sweep folder and stops. Nothing there is canon until a human routes it.

          prevented: a holding folder outliving its session and becoming the mess it was built to fix
        

        
08

          
Correct in place where the lane supports it. Batch and bump once where it does not.

          
Corrections do not deserve a version. Substance does.

          prevented: six master-directory versions produced in a single day, one correction at a time

        Operations
        
The one job that is yours

        
Everything runs on its own except the decisions. The operating burden
           is not uptime or tuning. It is answering gates. The daily loop takes
           minutes; skipping it stops the system.

      

      

        
    
          
  1. 
            
    Answer your gates
    
            
    Read the rendered payload, the actual text that would be written.
               Approve, edit first, or reject. A rejection halts the run and keeps
               its reason; nothing is lost by refusing.
    
          
    2. 
          
  2. 
            
    Check what the Council recalled
    
            
    If memory use is climbing while answers get worse, you have
               accumulated a bad memory. Correct or pause it. Bad memory
               compounds into every future answer.
    
          
    3. 
          
  3. 
            
    Watch simulated mode
    
            
    If the provider is mock, every response is labeled simulated.
               Deterministic, offline, useful for testing flows, useless for
               actual judgment.
    
          
    4. 
          
  4. 
            
    Weekly: ten minutes
    
            
    Gates older than a few days, token spend by workflow, memory
               hygiene, halted-run patterns, and schedule health. A pattern of
               rejections means the workflow's prompt is wrong. Edit the step.
    
          
    5. 
        

        

          
What drives the bill

          
Three settings, in order of how much they hurt.

          

            full_council: true×3
            Nine seats instead of 3 or 4. Roughly triples a run.
          

          

            deliberate: true×2
            A second round where every agent re-reads the others.
          

          

            trigger: hourly×24
            Hourly is 24× daily. This is the one that actually hurts.
          

          
All three together ≈ 50× a single-agent daily run. There is no budget cap. Watch the per-run token records yourself.

        

      

    

  


  
  

    

      

        Doctrine
        
Non-negotiables

        
The rules the whole product rests on. They hold in every mode, on every
           plan, in every environment.

      

      
    
        
  1. 01Not a chatbot: Council and synthesis only
    2. 
        
  2. 02Humans decide; agents recommend
    3. 
        
  3. 03Automation never commits effects unattended
    4. 
        
  4. 04Memory is transparent, editable, deletable
    5. 
        
  5. 05Simulated output is always labeled simulated
    6. 
      

      

        

          
Never

          
    
            
  • Never set WORKFLOW_APPROVAL_REQUIRED=false. It silently removes the guarantee everything rests on, and no incident is fixed by it.
    • 
            
  • Never edit the frozen baseline schema. Changes ship as migrations.
    • 
            
  • Never resolve someone else's gate. Approvals are recorded under your user id, and a shared account makes the audit trail a fiction.
    • 
            
  • Never downgrade past the migration that holds workflow_runs. That is where every approval record lives.
    • 
          

        

        

          
What it will not do, and says so

          
    
            
  • Send anything outbound. Exports render into the run record for you to read and copy.
    • 
            
  • Bill anyone, or share permissions across a team.
    • 
            
  • Enforce a spend limit for you.
    • 
            
  • Decide anything. It recommends; you record the call.
    •
