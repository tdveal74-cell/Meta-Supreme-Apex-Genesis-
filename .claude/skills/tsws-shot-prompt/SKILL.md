# TSWS shot prompts

How to turn one TSWS shot into prompts that a generator can run and a reviewer can check, without inventing canon. The canon itself is not in this file. It lives on Drive and changes by dated ruling, so every run starts by reading it. This file holds the method and what was measured the first time it ran.

For SH020, SH070 and SH100 also load `tsws-repair-workflows`. It holds those shots' repair history and the measurements behind them. Its boundary of no paid generation governs its repair methods; a paid generation under this skill is Tee's budget call, asked on a card (see "Spend" below).

## Read the canon first, every time

The precedence rule from Visual Bible v2.11 governs: newest filed ruling first, then the skill, data stores, packages, and the bible last. The skill in that ladder is `shadow-we-share-brand`, which the bible's store table names as brand law, not this file. Older production books on Drive still carry superseded directions, so check every source's date before using a line from it. The bible says what the ladder settles: when the bible and a store disagree, the store wins, and when stores disagree, the newest filed ruling wins. Where no filed ruling covers the point, the canon leaves the text as written and flags it, because rewriting it changes canon rather than restating it. That is a real contradiction. It goes to Tee on an `AskUserQuestion` card; never resolve one yourself. A disagreement the ladder does settle can still go on a card when following it rewrites drafted work, as the SH070 stopper did on 2026-10-30, with the ladder's answer as the recommended option.

## The method

Steps 6 to 8 were worked out on the chained Episode 1 street shots, where one shot's end still is the next shot's start frame. For any other shot, say which of them apply and why the rest do not.

1. **Pick the shot from the record, not from memory.** The manifest names each shot's editor verdict and logged defects. Start there and quote the exact cue.
2. **Get the native master and verify it.** The Drive connector refuses downloads over 10 MB. A larger master downloads only while it is link-shared, which Tee switches by hand in the Drive app. Check the sha256 against the editor's record. Afterwards, ask Tee to set it back to Restricted, then read back both its permissions and an unsigned download. On 2026-10-30 the SH020 and SH150 masters were found still open to anyone with the link, left that way since 2026-10-16. Tee set both to Restricted the same day, and the read back showed only the owner on each and a sign-in page for an unsigned download (Ruling 3 of 2026-10-30).
3. **Look at the frames person by person.** Extract the first and last frames at native size plus a contact sheet across the take. Write a table of every visible person: what they carry at each end and what they need. Note who leaves or enters the frame. Then read the table against the manifest's Logged Defects. For SH020 the editor had logged costume-like masks, an unmasked beige-coat face and a hair and shell discontinuity at f168/185. The table added whose hair changes (the maroon-scarf pedestrian, a knit cap at frame 0 and longer locs at frame 191), masks appearing on bare faces partway through the take, and two walkers seen from behind entering at the right edge from about frame 120.
4. **Answer the guide's six questions, then choose three to five controls.** Write the stills prompt as five to ten decisive instructions. Append P41 to stills only, never to motion prompts. Where a shot has no gold thread, replace P41's last sentence, "Keep the specified mask and thread state.", with a sentence naming the mask state.
5. **Write the motion prompt to match its own endpoints.** Give one action and the camera behaviour. Name who leaves frame and who enters, and say that nobody appears or vanishes inside the frame. A prompt that says "no new people" while the closing frame holds people the opening frame does not invites a first-and-last-frame model to morph them in.
6. **Keep the locked camera.** The five Episode 1 street shots share one camera (Ruling 1 of 2026-10-30). SH020, SH070 and SH100 are locked off, with under 0.5 px of skyline shift inside each take (manifest, Measured Metrics). SH150's take is not: it pans from frame 0, about 89 px by f191, with a -25,+3 px skyline shift at f95, so its native last frame is off the locked framing. It needs a per-frame camera solve or a ruling from Tee before it serves as an end still; `tsws-repair-workflows` has the measurements. SH135 is not regenerated either: its v10 still stays archived and byte-identical, and the Visual Bible's current repair status lists a separate v11 Venetian composite prepared under Tee's authorization on 2026-10-25. A street shot generated from text alone breaks continuity with its neighbours, so generate stills from the native frames and animate between them.
7. **Make the end frame first.** The end still is also the next shot's start frame. Pin anyone who also appears in the downstream approved frame to that frame's mask and hair. Then make the start still from the native first frame.
8. **Give the start still a head sheet, not the end still.** Crop the masked heads from the accepted end still onto a neutral grey sheet. Pass that as the second image, with one sentence saying it is a sheet of reference heads and not a scene. This rests on one A/B pair (see the receipts and "Still unverified").
9. **Check every still before any video runs.** See "Checking a still" below. If one check fails, repair that defect without a paid run where you can. A corrective re-run is paid, so it waits for Tee's answer on a card, and it changes one variable at a time, as the realism guide's retest rule says.
10. **Save what was submitted.** Keep each submitted prompt verbatim, plus the prediction id, the output sha256 and the price, in the job record, and carry that record into the arc's dated status doc.

## Checking a still

Run `.claude/skills/tsws-shot-prompt/scripts/align_still.py NATIVE.png EDITED.png OUT_PREFIX --boxes "name=x0,y0,x1,y1"` with the Python of a throwaway virtual environment in the session scratchpad (`pip install opencv-python-headless numpy`), never the project's own, because this repository does not pin OpenCV. It resizes the edit to native size, fits an affine, and prints the shift of three static regions before and after the fit. It writes the aligned still and a change map, then prints the shift of each person named in `--boxes`. It prints numbers only. You compare them with the notes below and write the verdict.

Its built-in regions were drawn on background that no person crosses in either SH020 native frame, and they hold only for the 1920x1080 street plate, so the script refuses any other native size unless `--regions` names new ones. A region with a person in it measures the person. The first version of these regions held a pedestrian's head in each native frame and read the end still 0.33 px off at worst, where people-free regions read 0.56 px.

- **Size.** Nano Banana Pro edit at 2K returned 2752x1536 on every run on 2026-10-30, about 0.8% wider than 16:9. A plain resize to 1920x1080 left the static regions 1.9 to 3.7 px off vertically. After the affine fit, the delivered start still sat within 0.09 px in all three regions. The delivered end still's skyline sat within 0.08 px, but its lobby stayed 0.56 px off vertically, because the edit did not move every part of the frame together. Never stretch blindly. Align, measure every region, and report the worst one.
- **People.** The end still's edit moved bodies by about 8 to 19 px. Pasting new heads onto native bodies would then leave neck seams, so the aligned full render was kept. The start still's retry held every person within 0.2 px and was still kept as a full render, so that both stills came from one model and their textures match. Composite heads onto the native frame only when the bodies barely move and a texture mismatch with the other still does not matter; no threshold for "barely" has been measured. Record which you did and why.
- **Added and removed people.** Compare the edges of the frame as well as the subjects. The SH020 end-still edit dropped two walkers seen from behind and added a background man by the lobby. People with no visible face can be restored from native pixels along a minimum-difference seam, with no paid run.
- **Masks before the fall** (SH020, SH070 and the start of SH100). Every visible street face wears a physically fitted Venetian-style eye and nose half-mask, each with a stable identity, silhouette, material, color, ornament and attachment, and no superseded design remains: no medical masks, skin-shell faces, feathers, headpieces, horns or Anahata decoration. Background masks belong to one restrained Venetian family, and the approved Auren and Vespera pair is not indiscriminately cloned across the crowd; the canon does not require every mask to be unique. A pedestrian whose mask a dated ruling names, such as the maroon-scarf pedestrian's mottled navy half-mask with gold flecks and a gold rim, wears exactly that mask. Each person who keeps a mask across two stills wears the same one in both. At 4x zoom, a small dark eye mask can read as sunglasses; flag it rather than pass it.
- **Masks from the fall on.** In SH100 the same worn mask detaches intact and falls, and the face beneath stays intact, with no hand removal, melting or face substitution. From then on the street crowd is unmasked, and both leads keep their masks through Episode 1's closing return.
- **Realism gate.** Reject or mark pending on skin smoothing, anatomy drift, invented or sterile environment detail, implausible reflections or shadows, staged gaze, changing proportions, or mask or mouth instability.

## WaveSpeed and Cinema Studio

- **Spend only on Tee's answer.** A paid run is his budget call. Put the quote on an `AskUserQuestion` card, recommended option first, each option's cost in its own description, and run after he answers. A ruling of his that names the shot and the model covers the runs it names. WaveSpeed is not on the gate ledger's server list, so nothing but this rule stops an unasked run.
- **Price before every run.** `get_price` and `estimate_only` are free. Quotes on 2026-10-30, at the discounted rate with list in brackets: Nano Banana Pro edit at 2K, $0.126 ($0.14). Kling 4.0 at 8 s, 1080p, first and last frame, $1.504 ($1.88); at 720p, $1.005 ($1.256). Seedance 2.5, same shot, no audio, $6.48 ($7.20). Re-quote; never reuse these.
- **Model choice.** The SH020 stills used Nano Banana Pro edit at 2K. The motion model is not settled: Kling 4.0 and Seedance 2.5 were quoted and neither has run. Put the choice to Tee on a card with the quotes.
- **Getting a still to the model.** The connector takes file URLs, not local paths. On 2026-10-30 each input went up through `create_upload` and a PUT to the address it returned.
- **Cinema Studio is a website feature only.** No API, command line or MCP route reaches it, checked 2026-10-30 against the docs, `llms.txt`, the CLI 0.4.24 source and the connector's tools. It runs ordinary catalog models (Seedance 2.5 and 2.0, Wan 3.0, Kling 4.0, MiniMax H3) and writes the director-panel choices into the prompt on WaveSpeed's side. Whether its "prompt sent to the model" view shows that expanded text after a run is unverified, so leave the panel cards on Auto, turn Enhance off and write the camera direction into your own prompt. The submitted text can then be saved verbatim.
- **First and last frames.** The Kling 4.0 API (`kwaivgi/kling-v4.0/image-to-video`) takes `image` and `last_image`, 3 to 30 s, 720p or 1080p. Whether the Cinema Studio composer shows a last-frame slot was unverified on 2026-10-30. If it does not, run the same prompt on the model page or through the connector.
- **Audio.** Set it off where the tool allows, and strip it before placement regardless. Conform to the 30 fps timeline.
- **Never resubmit a run that timed out on the client.** The run keeps going on the server. Poll it with `get_prediction` and a `wait_seconds` under 60. The schema allows 100, but a call with 100 on 2026-10-30 came back "timed out after 60s" from the client.
